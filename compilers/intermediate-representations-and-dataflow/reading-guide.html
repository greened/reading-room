Compilers · Intermediate representations & dataflow

IR design and the dataflow-analysis frameworks every optimizer rests on — from flow-graph reducibility and interval/structural analysis through SSA and the sea-of-nodes graph. (Muchnick's *Advanced Compiler Design* is the companion text.)

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. A Unified Approach to Global Program Optimization
    PDFDOI · PDF
    Gary A. Kildall, 1973, POPL. Founded lattice-theoretic dataflow: the first unified fixed-point framework.
  2. Characterizations of Reducible Flow Graphs
    DOIDOI
    Hecht, Ullman, 1974, JACM. Equivalent characterizations of reducibility (T1/T2, dominator back edges).
  3. Testing Flow Graph Reducibility
    DOIDOI
    Robert E. Tarjan, 1974, JCSS. Efficient DFS + union-find reducibility test. 80049-8)
  4. A Program Data Flow Analysis Procedure
    PDFDOI · PDF
    Allen, Cocke, 1976, CACM. Introduced interval analysis (the classic elimination approach).
  5. A Fast and Usually Linear Algorithm for Global Flow Analysis
    DOIDOI
    Graham, Wegman, 1976, JACM. Near-linear elimination for reducible graphs.
  6. Monotone Data Flow Analysis Frameworks
    DOIDOI
    Kam, Ullman, 1977, Acta Informatica. Generalized Kildall to monotone functions; MFP vs MOP.
  7. Structural Analysis: A New Approach to Flow Analysis
    DOIDOI
    Micha Sharir, 1980, Computer Languages. Syntax-directed elimination over control-flow constructs. 90007-7)
  8. The Program Dependence Graph and Its Use in Optimization
    PDFDOI · PDF
    Ferrante, Ottenstein, Warren, 1987, ACM TOPLAS. Made data and control dependences explicit; basis for slicing/vectorization.
  9. Global Value Numbers and Redundant Computations
    DOIDOI
    Rosen, Wegman, Zadeck, 1988, POPL. SSA + value numbering for value-equivalent redundancy.
  10. The Program Dependence Web
    DOIDOI
    Ballance, Maccabe, Ottenstein, 1990, PLDI. Gated SSA + a control/data/demand-driven IR.
  11. Efficiently Computing SSA Form and the Control Dependence Graph
    DOIDOI
    Cytron, Ferrante, Rosen, Wegman, Zadeck, 1991, ACM TOPLAS. The dominance-frontier SSA construction; made SSA the standard IR.
  12. A Simple Graph-Based Intermediate Representation
    DOIDOI
    Click, Paleczny, 1995, IR'95. The sea-of-nodes IR behind HotSpot C2, V8 TurboFan, and other JITs.
