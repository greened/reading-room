Compilers — Landmark Papers

A cross-cutting survey of the field's most important papers. Folder: reading-room/compilers/ · canonical references live in the sibling subtopic dirs.

Roughly a dozen papers that define compiler construction and optimization, in a sensible reading order (the machinery every optimizer rests on, then the reusable-infrastructure and verification landmarks). Each entry points to the subtopic dir that treats it in depth.   Legend: PDFopen copy available (see fetch.sh) · DOIpublisher link only.

  1. A Unified Approach to Global Program Optimization — Gary A. Kildall
    PDFPOPL 1973 · doi:10.1145/512927.512945 · → intermediate-representations-and-dataflow/
    Founds the lattice / monotone-framework view of iterative dataflow analysis.
  2. Efficiently Computing Static Single Assignment Form and the Control Dependence Graph — Cytron, Ferrante, Rosen, Wegman, Zadeck
    PDFACM TOPLAS 1991 · doi:10.1145/115372.115320 · → intermediate-representations-and-dataflow/
    The dominance-frontier SSA-construction algorithm that made SSA the default IR of modern compilers.
  3. Abstract Interpretation: A Unified Lattice Model for Static Analysis — Patrick & Radhia Cousot
    PDFPOPL 1977 · doi:10.1145/512950.512973 · → abstract-interpretation/
    The theoretical framework for sound static analysis via Galois connections and widening.
  4. Register Allocation and Spilling via Graph Coloring — Gregory J. Chaitin
    PDFSIGPLAN Compiler Construction 1982 · doi:10.1145/872726.806984 · → register-allocation-and-scheduling/
    The original graph-coloring formulation that launched the whole line of register-allocation work.
  5. Lazy Code Motion — Knoop, Rüthing, Steffen
    PDFPLDI 1992 · doi:10.1145/143095.143136 · → classical-optimization/
    The clean, optimal formulation of partial-redundancy elimination.
  6. LLVM: A Compilation Framework for Lifelong Program Analysis & Transformation — Lattner, Adve
    PDFCGO 2004 · doi:10.1109/CGO.2004.1281665 · → compiler-infrastructure/
    Launched LLVM, now the dominant reusable compiler infrastructure in industry and research.
  7. A Practical Automatic Polyhedral Parallelizer and Locality Optimizer (Pluto) — Bondhugula, Hartono, Ramanujam, Sadayappan
    PDFPLDI 2008 · doi:10.1145/1375581.1375595 · → compiler-infrastructure/
    Made the polyhedral model a practical automatic tiling and parallelization engine.
  8. Formal Verification of a Realistic Compiler (CompCert) — Xavier Leroy
    PDFCACM 2009 · doi:10.1145/1538788.1538814 · → verified-compilation/
    The first mechanically verified optimizing C compiler — the reference point for verified compilation.
  9. Halide: A Language and Compiler for Optimizing Image Processing Pipelines — Ragan-Kelley et al.
    PDFPLDI 2013 · doi:10.1145/2491956.2462176 · → compiler-infrastructure/
    The algorithm/schedule separation that reshaped how DSL and tensor compilers are designed.
  10. Stochastic Superoptimization (STOKE) — Schkufza, Sharma, Aiken
    PDFASPLOS 2013 · doi:10.1145/2451116.2451150 · → verified-compilation/
    Reframes superoptimization as MCMC search over programs, finding code beyond rule-based reach.
  11. Provably Correct Peephole Optimizations with Alive — Lopes, Menendez, Nagarakatte, Regehr
    PDFPLDI 2015 · doi:10.1145/2737924.2737965 · → verified-compilation/
    SMT-based verification of LLVM peephole optimizations, now a real part of LLVM development.
  12. MLIR: Scaling Compiler Infrastructure for Domain Specific Computation — Lattner et al.
    PDFCGO 2021 · doi:10.1109/CGO51591.2021.9370308 · → compiler-infrastructure/
    The multi-level, dialect-based IR framework now central to ML and accelerator compiler stacks.

Going deeper

This survey is the slice across the whole area; each subtopic dir treats its theme in depth and lists more papers.

  • DIRintermediate-representations-and-dataflow/ — reducibility, dataflow frameworks, SSA, PDG, sea-of-nodes.
  • DIRclassical-optimization/ — SCCP, value numbering, PRE/lazy code motion, strength reduction, partial evaluation.
  • DIRregister-allocation-and-scheduling/ — graph coloring, coalescing, linear scan, SSA-based allocation, scheduling, software pipelining.
  • DIRvectorization-and-parallelization/ — dependence analysis, loop transforms, polyhedral, SLP, work-stealing, TLS.
  • DIRpointer-analysis/ — Andersen/Steensgaard, context/flow/object sensitivity at scale.
  • DIRabstract-interpretation/ — numeric domains, widening/narrowing, IFDS, shape analysis, Astrée.
  • DIRcompiler-infrastructure/ — LLVM, polyhedral/Pluto, Halide/TVM/MLIR, BOLT.
  • DIRverified-compilation/ — CompCert, CakeML, Alive, egg, STOKE.

Reference shelf — books

The standard texts for the area; free copies linked where a legal one exists.

  • BUYCompilers: Principles, Techniques, and Tools (Dragon Book) — Aho, Lam, Sethi, Ullman (2nd ed., 2006) · the canonical survey of lexing, parsing, semantics, and code generation. page
  • BUYAdvanced Compiler Design and Implementation — Steven S. Muchnick (1997) · the deepest single-volume treatment of production optimization and SSA-era analyses. page
  • BUYEngineering a Compiler — Cooper, Torczon (3rd ed., 2022) · modern, engineering-focused course text. page
  • BUYModern Compiler Implementation in ML — Andrew W. Appel (1998) · builds a complete compiler end to end. page
  • BUYOptimizing Compilers for Modern Architectures — Allen, Kennedy (2001) · the reference on dependence analysis, loop transforms, and parallelization. page
  • BUYPrinciples of Program Analysis — Nielson, Nielson, Hankin (1999) · rigorous unifying treatment of dataflow, CFA, abstract interpretation, type/effect analyses. page
  • FREECrafting Interpreters — Robert Nystrom (2021) · hands-on: builds a tree-walk and a bytecode interpreter from scratch (free HTML). page
