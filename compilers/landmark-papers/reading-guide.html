Compilers — Landmark Papers

A cross-cutting survey of the field's most important papers. Folder: reading-room/compilers/ · canonical references live in the sibling subtopic dirs.

Reading order: foundations first, then the post-2002 landmarks (weighted per the reader's interest). Each entry points to the subtopic dir that treats it in depth.   Legend: PDFopen copy (see fetch.sh) · DOIpublisher link.

This is the area survey — roughly a dozen papers that define compiler construction and optimization. For a deeper pass on any theme, follow the subtopic pointer (e.g. register-allocation-and-scheduling/).

Foundations (pre-2002)

The IR, dataflow, analysis, allocation, and redundancy machinery every optimizer still rests on.

  1. A Unified Approach to Global Program Optimization — Gary A. Kildall
    PDFPOPL 1973 · doi:10.1145/512927.512945 · → ir-and-dataflow/
    Founds the lattice / monotone-framework view of iterative dataflow analysis.
  2. Efficiently Computing Static Single Assignment Form and the Control Dependence Graph — Cytron, Ferrante, Rosen, Wegman, Zadeck
    PDFACM TOPLAS 1991 · doi:10.1145/115372.115320 · → ir-and-dataflow/
    The dominance-frontier SSA-construction algorithm that made SSA the default IR of modern compilers.
  3. Abstract Interpretation: A Unified Lattice Model for Static Analysis — Patrick & Radhia Cousot
    PDFPOPL 1977 · doi:10.1145/512950.512973 · → analysis-and-abstract-interpretation/
    The theoretical framework for sound static analysis via Galois connections and widening.
  4. Register Allocation and Spilling via Graph Coloring — Gregory J. Chaitin
    PDFSIGPLAN Compiler Construction 1982 · doi:10.1145/872726.806984 · → register-allocation-and-scheduling/
    The original graph-coloring formulation that launched the whole line of register-allocation work.
  5. Lazy Code Motion — Knoop, Rüthing, Steffen
    PDFPLDI 1992 · doi:10.1145/143095.143136 · → redundancy-and-vectorization/
    The clean, optimal formulation of partial-redundancy elimination.

Modern landmarks (post-2002)

Reusable infrastructure, the polyhedral/DSL/tensor wave, verified compilation, and search-based optimization.

  1. LLVM: A Compilation Framework for Lifelong Program Analysis & Transformation — Lattner, Adve
    PDFCGO 2004 · doi:10.1109/CGO.2004.1281665 · → compiler-infrastructure/
    Launched LLVM, now the dominant reusable compiler infrastructure in industry and research.
  2. A Practical Automatic Polyhedral Parallelizer and Locality Optimizer (Pluto) — Bondhugula, Hartono, Ramanujam, Sadayappan
    PDFPLDI 2008 · doi:10.1145/1375581.1375595 · → compiler-infrastructure/
    Made the polyhedral model a practical automatic tiling and parallelization engine.
  3. Formal Verification of a Realistic Compiler (CompCert) — Xavier Leroy
    PDFCACM 2009 · doi:10.1145/1538788.1538814 · → verified-compilation/
    The first mechanically verified optimizing C compiler — the reference point for verified compilation.
  4. Halide: A Language and Compiler for Optimizing Image Processing Pipelines — Ragan-Kelley et al.
    PDFPLDI 2013 · doi:10.1145/2491956.2462176 · → compiler-infrastructure/
    The algorithm/schedule separation that reshaped how DSL and tensor compilers are designed.
  5. Stochastic Superoptimization (STOKE) — Schkufza, Sharma, Aiken
    PDFASPLOS 2013 · doi:10.1145/2451116.2451150 · → verified-compilation/
    Reframes superoptimization as MCMC search over programs, finding code beyond rule-based reach.
  6. Provably Correct Peephole Optimizations with Alive — Lopes, Menendez, Nagarakatte, Regehr
    PDFPLDI 2015 · doi:10.1145/2737924.2737965 · → verified-compilation/
    SMT-based verification of LLVM peephole optimizations, now a real part of LLVM development.
  7. MLIR: Scaling Compiler Infrastructure for Domain Specific Computation — Lattner et al.
    PDFCGO 2021 · doi:10.1109/CGO51591.2021.9370308 · → compiler-infrastructure/
    The multi-level, dialect-based IR framework now central to ML and accelerator compiler stacks.
