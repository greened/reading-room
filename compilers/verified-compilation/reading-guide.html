Compilers · Verified compilation & superoptimization

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. Formal Verification of a Realistic Compiler (CompCert)
    PDFDOI · PDF
    Xavier Leroy, 2009, CACM. The first mechanically verified optimizing C compiler; the reference point for verified compilation.
  2. CakeML: A Verified Implementation of ML
    PDFDOI · PDF
    Kumar, Myreen, Norrish, Owens, 2014, POPL. End-to-end verified compiler and runtime, proof reaching to machine code.
  3. Provably Correct Peephole Optimizations with Alive
    PDFDOI · PDF
    Lopes, Menendez, Nagarakatte, Regehr, 2015, PLDI. SMT-based verification of LLVM peephole optimizations, now part of LLVM practice.
  4. egg: Fast and Extensible Equality Saturation
    DOIDOI
    Willsey et al., 2021, PACMPL (POPL). The practical e-graph library that made equality saturation broadly usable.
  5. Stochastic Superoptimization (STOKE)
    PDFDOI · PDF
    Schkufza, Sharma, Aiken, 2013, ASPLOS. Reframes superoptimization as MCMC search over programs.
