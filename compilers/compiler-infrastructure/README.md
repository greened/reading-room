# Compilers · Modern infrastructure, polyhedral & tensor compilers

- **LLVM: A Compilation Framework for Lifelong Program Analysis & Transformation** — Chris Lattner, Vikram Adve, 2004, CGO. *post-2002.* Launched LLVM, now the dominant reusable compiler infrastructure. [DOI](https://doi.org/10.1109/CGO.2004.1281665) · [PDF](https://llvm.org/pubs/2004-01-30-CGO-LLVM.pdf)
- **A Practical Automatic Polyhedral Parallelizer and Locality Optimizer (Pluto)** — Bondhugula, Hartono, Ramanujam, Sadayappan, 2008, PLDI. *post-2002.* Made the polyhedral model a practical automatic tiling/parallelization engine. [DOI](https://doi.org/10.1145/1375581.1375595) · [PDF](https://www.ece.lsu.edu/jxr/Publications-pdf/pldi08.pdf)
- **Halide: A Language and Compiler for Optimizing Parallelism, Locality, and Recomputation in Image Processing Pipelines** — Ragan-Kelley et al., 2013, PLDI. *post-2002.* The algorithm/schedule separation that reshaped DSL and tensor compilers. [DOI](https://doi.org/10.1145/2491956.2462176) · [PDF](https://people.csail.mit.edu/jrk/halide-pldi13.pdf)
- **TVM: An Automated End-to-End Optimizing Compiler for Deep Learning** — Chen et al., 2018, OSDI. *post-2002.* The archetypal end-to-end deep-learning compiler. [page](https://www.usenix.org/conference/osdi18/presentation/chen) · [PDF](https://arxiv.org/pdf/1802.04799)
- **MLIR: Scaling Compiler Infrastructure for Domain Specific Computation** — Lattner et al., 2021, CGO. *post-2002.* The multi-level, dialect-based IR framework central to modern ML/accelerator stacks. [DOI](https://doi.org/10.1109/CGO51591.2021.9370308) · [PDF](https://arxiv.org/pdf/2002.11054)
- **BOLT: A Practical Binary Optimizer for Data Centers and Beyond** — Panchenko, Auler, Nell, Ottoni, 2019, CGO. *post-2002.* State-of-the-art profile-guided post-link binary optimizer. [DOI](https://doi.org/10.1109/CGO.2019.8661201) · [PDF](https://arxiv.org/pdf/1807.06735)
