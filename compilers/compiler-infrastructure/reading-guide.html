Compilers · Modern infrastructure, polyhedral & tensor compilers

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. LLVM: A Compilation Framework for Lifelong Program Analysis & Transformation
    PDFDOI · PDF
    Chris Lattner, Vikram Adve, 2004, CGO. Launched LLVM, now the dominant reusable compiler infrastructure.
  2. A Practical Automatic Polyhedral Parallelizer and Locality Optimizer (Pluto)
    PDFDOI · PDF
    Bondhugula, Hartono, Ramanujam, Sadayappan, 2008, PLDI. Made the polyhedral model a practical automatic tiling/parallelization engine.
  3. Halide: A Language and Compiler for Optimizing Parallelism, Locality, and Recomputation in Image Processing Pipelines
    PDFDOI · PDF
    Ragan-Kelley et al., 2013, PLDI. The algorithm/schedule separation that reshaped DSL and tensor compilers.
  4. TVM: An Automated End-to-End Optimizing Compiler for Deep Learning
    PDFpage · PDF
    Chen et al., 2018, OSDI. The archetypal end-to-end deep-learning compiler.
  5. MLIR: Scaling Compiler Infrastructure for Domain Specific Computation
    PDFDOI · PDF
    Lattner et al., 2021, CGO. The multi-level, dialect-based IR framework central to modern ML/accelerator stacks.
  6. BOLT: A Practical Binary Optimizer for Data Centers and Beyond
    PDFDOI · PDF
    Panchenko, Auler, Nell, Ottoni, 2019, CGO. State-of-the-art profile-guided post-link binary optimizer.
