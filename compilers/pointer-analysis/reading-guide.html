Compilers · Pointer / alias analysis

One of the hardest static-analysis problems: deciding what pointers may refer to. Andersen (inclusion) and Steensgaard (unification) anchor the field; the rest add context-, flow-, field-, and object-sensitivity and scale it to millions of lines.

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. Context-Sensitive Interprocedural Points-to Analysis in the Presence of Function Pointers
    DOIDOI
    Emami, Ghiya, Hendren, 1994, PLDI. Context-sensitive interprocedural points-to for C with an invocation-graph treatment of function pointers.
  2. Program Analysis and Specialization for the C Programming Language
    PDFPDF
    Lars Ole Andersen, 1994, PhD thesis (DIKU). Origin of "Andersen-style" inclusion (subset-constraint) analysis.
  3. Points-to Analysis in Almost Linear Time
    PDFDOI · PDF
    Bjarne Steensgaard, 1996, POPL. "Steensgaard-style" unification analysis: precision traded for near-linear scale.
  4. Unification-Based Pointer Analysis with Directional Assignments
    PDFDOI · PDF
    Manuvir Das, 2000, PLDI. "One-level flow" interpolates between Steensgaard and Andersen.
  5. Ultra-fast Aliasing Analysis using CLA (a million lines of C in a second)
    PDFDOI · PDF
    Heintze, Tardieu, 2001, PLDI. Field-based Andersen-style analysis at enormous scale.
  6. Pointer Analysis: Haven't We Solved This Problem Yet?
    PDFDOI · PDF
    Michael Hind, 2001, PASTE. The canonical survey framing the design dimensions and open problems.
  7. Cloning-Based Context-Sensitive Pointer Alias Analysis Using BDDs
    PDFDOI · PDF
    Whaley, Lam, 2004, PLDI. Fully context-sensitive inclusion analysis made to scale via BDDs/Datalog (bddbddb).
  8. Parameterized Object Sensitivity for Points-to Analysis for Java
    DOIDOI
    Milanova, Rountev, Ryder, 2005, ACM TOSEM. Object-sensitivity: the dominant precision/scalability sweet spot for OO.
  9. Refinement-Based Context-Sensitive Points-to Analysis for Java
    PDFDOI · PDF
    Sridharan, Bodík, 2006, PLDI. Points-to as CFL-reachability with demand-driven refinement.
  10. The Ant and the Grasshopper: Fast and Accurate Pointer Analysis for Millions of Lines of Code
    PDFDOI · PDF
    Hardekopf, Lin, 2007, PLDI. Lazy/Hybrid Cycle Detection: dramatic speedups without precision loss.
  11. Pick Your Contexts Well: Understanding Object-Sensitivity
    DOIDOI
    Smaragdakis, Bravenboer, Lhoták, 2011, POPL. The definitive account of context choice (and type-sensitivity).
  12. Flow-Sensitive Pointer Analysis for Millions of Lines of Code
    DOIDOI
    Hardekopf, Lin, 2011, CGO. Sparse, staged flow-sensitive analysis with strong updates at scale.
