Compilers · Register allocation & instruction scheduling

Graph-coloring, coalescing, linear scan, and the SSA-era allocators; plus global instruction scheduling and software pipelining.

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. Register Allocation via Coloring
    DOIDOI
    Chaitin, Auslander, Chandra, Cocke, Hopkins, Markstein, 1981, Computer Languages. Cast register assignment as coloring the interference graph. 90048-5)
  2. Register Allocation & Spilling via Graph Coloring
    PDFDOI · PDF
    Gregory J. Chaitin, 1982, SIGPLAN Compiler Construction. The canonical Chaitin allocator: spill-cost model + simplify/spill.
  3. Improvements to Graph Coloring Register Allocation
    DOIDOI
    Briggs, Cooper, Torczon, 1994, ACM TOPLAS. Optimistic coloring + rematerialization (Chaitin-Briggs).
  4. Iterated Register Coalescing
    PDFDOI · PDF
    George, Appel, 1996, ACM TOPLAS. Conservative coalescing interleaved with simplification.
  5. Linear Scan Register Allocation
    PDFDOI · PDF
    Poletto, Sarkar, 1999, ACM TOPLAS. The fast non-coloring allocator over live intervals; ideal for JITs.
  6. Trace Scheduling
    PDFDOI · PDF
    Joseph A. Fisher, 1981, IEEE TC. The founding paper of global instruction scheduling across basic blocks.
  7. Some Scheduling Techniques and an Easily Schedulable Horizontal Architecture
    DOIDOI
    Rau, Glaeser, 1981, MICRO-14. Origin of modulo scheduling and rotating registers.
  8. Software Pipelining: An Effective Scheduling Technique for VLIW Machines
    PDFDOI · PDF
    Monica Lam, 1988, PLDI. Modulo scheduling with hierarchical reduction.
  9. Optimal Spilling for CISC Machines with Few Registers
    DOIDOI
    Appel, George, 2001, PLDI. ILP-optimal live-range splitting + spill placement.
  10. Register Allocation via Coloring of Chordal Graphs
    PDFDOI · PDF
    Pereira, Palsberg, 2005, APLAS. SSA interference graphs are chordal → optimal polynomial coloring.
  11. Register Allocation for Programs in SSA Form
    PDFDOI · PDF
    Hack, Grund, Goos, 2006, CC. Chordality → separate spilling, optimal coloring, coalescing phases.
  12. Register Allocation by Puzzle Solving
    PDFDOI · PDF
    Pereira, Palsberg, 2008, PLDI. Handles register aliasing (e.g. x86) as tractable puzzle-solving.
  13. Revisiting Out-of-SSA Translation for Correctness, Code Quality and Efficiency
    DOIDOI
    Boissinot, Darte, Rastello, Dupont de Dinechin, Guillon, 2009, CGO. Correct/efficient phi-elimination + coalescing for SSA-based allocation.
  14. Linear Scan Register Allocation on SSA Form
    DOIDOI
    Wimmer, Franz, 2010, CGO. Linear scan + SSA (HotSpot client allocator).
  15. Trace-based Register Allocation in a JIT Compiler
    DOIDOI
    Eisl, Grimmer, Simon, Würthinger, Mössenböck, 2016, PPPJ. Per-trace strategies trading compile time vs code quality.
