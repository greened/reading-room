Compilers · Abstract interpretation

The theory of sound static analysis by approximation — Galois connections, numeric domains (intervals, octagons, polyhedra), widening/narrowing, IFDS, and shape analysis — through to the industrial Astrée analyzer.

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

    PDFDOI · PDF
    Patrick & Radhia Cousot, 1977, POPL. The founding framework: sound analysis by fixpoint approximation.
  2. Automatic Discovery of Linear Restraints Among Variables of a Program
    PDFDOI · PDF
    Cousot, Halbwachs, 1978, POPL. The polyhedra domain: the first relational numeric domain.
  3. Systematic Design of Program Analysis Frameworks
    PDFDOI · PDF
    Cousot & Cousot, 1979, POPL. Galois connections and deriving analyses from a formal semantics.
  4. Affine Relationships Among Variables of a Program
    DOIDOI
    Michael Karr, 1976, Acta Informatica. Pioneering inference of affine equalities among variables.
  5. Comparing the Galois Connection and Widening/Narrowing Approaches
    PDFDOI · PDF
    Cousot & Cousot, 1992, PLILP. Reconciles the two abstraction styles for infinite-height domains.
  6. Precise Interprocedural Dataflow Analysis via Graph Reachability (IFDS)
    PDFDOI · PDF
    Reps, Horwitz, Sagiv, 1995, POPL. Reduces a large class of interprocedural problems to polynomial-time reachability.
  7. Solving Shape-Analysis Problems in Languages with Destructive Updating
    PDFDOI · PDF
    Sagiv, Reps, Wilhelm, 1998, ACM TOPLAS. Shape graphs for sound reasoning about the heap.
  8. Parametric Shape Analysis via 3-Valued Logic (TVLA)
    PDFDOI · PDF
    Sagiv, Reps, Wilhelm, 2002, ACM TOPLAS. The parametric, instantiable heap-abstraction methodology.
  9. A Static Analyzer for Large Safety-Critical Software (Astrée)
    PDFDOI · PDF
    Blanchet, Cousot, Cousot, Feret, Mauborgne, Miné, Monniaux, Rival, 2003, PLDI. The landmark industrial abstract interpreter (avionics).
  10. The Octagon Abstract Domain
    DOIDOI
    Antoine Miné, 2006, HOSC. The widely used weakly-relational domain between intervals and polyhedra.
