# Compilers

Reading lists for compiler construction and optimization, organized by subtopic.
Each subtopic directory holds the canonical paper references (annotated, with
links). The **[landmark-papers/](landmark-papers/)** subtopic is a cross-cutting
*survey* — the handful of most important papers across the whole area, rendered as
a printable guide.

Weighted toward landmarks published **after 2002**, with the essential earlier
foundations included.

## Subtopics

- **[landmark-papers/](landmark-papers/)** — the area survey (start here; printable PDF)
- **[ir-and-dataflow/](ir-and-dataflow/)** — IR design and dataflow analysis frameworks
- **[register-allocation-and-scheduling/](register-allocation-and-scheduling/)** — register allocation and instruction scheduling
- **[redundancy-and-vectorization/](redundancy-and-vectorization/)** — redundancy elimination and vectorization
- **[analysis-and-abstract-interpretation/](analysis-and-abstract-interpretation/)** — pointer analysis and abstract interpretation
- **[compiler-infrastructure/](compiler-infrastructure/)** — reusable frameworks, polyhedral, and tensor/DSL compilers
- **[verified-compilation/](verified-compilation/)** — verified compilation and superoptimization
