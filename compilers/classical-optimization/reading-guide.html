Compilers · Classical (scalar) optimization

The scalar optimizations that define the vocabulary of the field: constant propagation, value numbering, redundancy elimination, strength reduction, inlining, and partial evaluation.

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. A Catalogue of Optimizing Transformations
    PDFPDF
    Allen, Cocke, 1972, in *Design and Optimization of Compilers*. The first systematic catalogue (CSE, DCE, code motion, strength reduction, inlining).
  2. A Unified Approach to Global Program Optimization
    PDFDOI · PDF
    Gary A. Kildall, 1973, POPL. The dataflow foundation underlying constant propagation, CSE, and liveness.
  3. An Algorithm for Reduction of Operator Strength
    DOIDOI
    Cocke, Kennedy, 1977, CACM. Replacing loop induction-variable multiplies with additions.
  4. An Analysis of Inline Substitution for a Structured Programming Language
    DOIDOI
    Robert W. Scheifler, 1977, CACM. Inlining as a cost-constrained optimization.
  5. Global Optimization by Suppression of Partial Redundancies
    DOIDOI
    Morel, Renvoise, 1979, CACM. The seminal partial-redundancy elimination (PRE), unifying CSE and LICM.
  6. Detecting Equality of Variables in Programs
    DOIDOI
    Alpern, Wegman, Zadeck, 1988, POPL. Congruence over SSA value graphs; the basis of global value numbering.
  7. Global Value Numbers and Redundant Computations
    DOIDOI
    Rosen, Wegman, Zadeck, 1988, POPL. GVN detecting equivalent expressions and second-order redundancy.
  8. Constant Propagation with Conditional Branches (SCCP)
    PDFDOI · PDF
    Wegman, Zadeck, 1991, ACM TOPLAS. Sparse conditional constant propagation with unreachable-branch pruning.
  9. Lazy Code Motion
    PDFDOI · PDF
    Knoop, Rüthing, Steffen, 1992, PLDI. PRE recast as unidirectional analyses with computationally optimal placement.
  10. Partial Evaluation and Automatic Program Generation
    DOIbook
    Jones, Gomard, Sestoft, 1993, Prentice Hall. The definitive text; specialization and the Futamura projections.
  11. Global Code Motion / Global Value Numbering
    DOIDOI
    Cliff Click, 1995, PLDI. Separating value optimization from scheduling; standard in SSA compilers.
