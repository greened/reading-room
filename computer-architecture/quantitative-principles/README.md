# Computer architecture · Quantitative principles

- **Validity of the Single Processor Approach to Achieving Large Scale Computing Capabilities** — Gene M. Amdahl, 1967, AFIPS. *foundational.* The origin of Amdahl's Law and the serial-fraction speedup ceiling. [DOI](https://doi.org/10.1145/1465482.1465560) · [PDF](https://www3.cs.stonybrook.edu/~rezaul/Spring-2012/CSE613/reading/Amdahl-1967.pdf)
- **Amdahl's Law in the Multicore Era** — Mark D. Hill, Michael R. Marty, 2008, IEEE Computer. *post-2002.* Recasts Amdahl's Law for chip multiprocessors (symmetric/asymmetric/dynamic core mixes). [DOI](https://doi.org/10.1109/MC.2008.209)
- **Roofline: An Insightful Visual Performance Model for Multicore Architectures** — Williams, Waterman, Patterson, 2009, CACM. *post-2002.* A single bound-and-bottleneck plot tying performance to operational intensity and bandwidth. [DOI](https://doi.org/10.1145/1498765.1498785)
- **A New Golden Age for Computer Architecture** — Hennessy, Patterson, 2019, CACM. *post-2002.* The Turing-Lecture manifesto for domain-specific architectures and open ISAs. [DOI](https://doi.org/10.1145/3282307)
