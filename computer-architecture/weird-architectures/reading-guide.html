Computer architecture · Weird / unconventional architectures

The roads less taken: dataflow machines, transport-triggered and decoupled designs, systolic and VLIW, massively-parallel SIMD, and tiled processors.

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. A Preliminary Architecture for a Basic Data-Flow Processor
    DOIDOI
    Dennis, Misunas, 1974, ISCA. The seminal static dataflow processor.
  2. Executing a Program on the MIT Tagged-Token Dataflow Architecture
    DOIDOI
    Arvind, Nikhil, 1990, IEEE TC. Dynamic (tagged-token) dataflow.
  3. Monsoon: An Explicit Token-Store Architecture
    DOIDOI
    Papadopoulos, Culler, 1990, ISCA. The explicit token-store design that made dynamic dataflow buildable.
  4. MOVE: A Framework for High-Performance Processor Design
    DOIDOI
    Corporaal, Mulder, 1991, Supercomputing. Transport-triggered architectures (program the data movement).
  5. Why Systolic Architectures?
    DOIDOI
    H. T. Kung, 1982, IEEE Computer. The systolic-array paradigm (also foundational to modern ML accelerators).
  6. The WM Computer Architecture
    DOIDOI
    Wm. A. Wulf, 1988, SIGARCH CAN. An unconventional streaming design treating operand streams as first-class.
  7. Decoupled Access/Execute Computer Architectures
    DOIDOI
    James E. Smith, 1982, ISCA. Splitting memory-access from execution into decoupled queues.
  8. Very Long Instruction Word Architectures and the ELI-512
    DOIDOI
    Joseph A. Fisher, 1983, ISCA. The founding VLIW paper (with trace scheduling).
  9. The Manchester Prototype Dataflow Computer
    DOIDOI
    Gurd, Kirkham, Watson, 1985, CACM. The most complete built-and-measured tagged-token dataflow machine.
  10. Data Parallel Algorithms
    DOIDOI
    Hillis, Steele, 1986, CACM. The Connection Machine article crystallizing massively-parallel SIMD.
  11. The Transputer
    DOIDOI
    Colin Whitby-Strevens, 1985, ISCA. INMOS's message-passing, on-chip-links processor (with occam/CSP).
  12. Baring It All to Software: Raw Machines
    DOIDOI
    Waingold, Taylor, et al., 1997, IEEE Computer. The tiled, software-exposed Raw architecture, prefiguring spatial accelerators.
