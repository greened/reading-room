Computer architecture · Simulation & modeling tools

The infrastructure of the field: cycle-level and full-system simulators, power/area models, DRAM models, instrumentation, and sampling methodology.

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. The gem5 Simulator
    PDFDOI · PDF
    Binkert, Beckmann, Black, Reinhardt, Saidi, Basu, Hestness, Hower, Krishna, Sardashti, Sen, Sewell, Shoaib, Vaish, Hill, Wood, 2011, SIGARCH CAN. The M5+GEMS merger that became the de facto full-system, cycle-level simulator.
  2. The gem5 Simulator: Version 20.0+
    PDFarXiv · PDF
    Lowe-Power et al., 2020, arXiv. The decade-later community retrospective and standard modern citation.
  3. The SimpleScalar Tool Set, Version 2.0
    DOIDOI
    Burger, Austin, 1997, SIGARCH CAN. The dominant execution-driven microarchitecture simulator of its era.
  4. Wattch: A Framework for Architectural-Level Power Analysis and Optimizations
    DOIDOI
    Brooks, Tiwari, Martonosi, 2000, ISCA. The first widely-adopted architectural dynamic-power model.
  5. McPAT: An Integrated Power, Area, and Timing Modeling Framework
    DOIDOI
    Li, Ahn, Strong, Brockman, Tullsen, Jouppi, 2009, MICRO-42. The standard multicore power/area/timing companion to perf simulators.
  6. DRAMSim2: A Cycle Accurate Memory System Simulator
    DOIDOI
    Rosenfeld, Cooper-Balis, Jacob, 2011, IEEE CAL. A widely-used cycle-accurate DRAM model.
  7. ZSim: Fast and Accurate Microarchitectural Simulation of Thousand-Core Systems
    PDFDOI · PDF
    Sanchez, Kozyrakis, 2013, ISCA. Instruction-driven timing + bound-weave parallelization at thousand-core scale.
  8. Sniper: Exploring the Level of Abstraction for Scalable and Accurate Parallel Multi-Core Simulation
    DOIDOI
    Carlson, Heirman, Eeckhout, 2011, SC. Popularized interval simulation for large multicores.
  9. Pin: Building Customized Program Analysis Tools with Dynamic Instrumentation
    DOIDOI
    Luk, Cohn, Muth, Patil, Klauser, Lowney, Wallace, Reddi, Hazelwood, 2005, PLDI. The DBI framework underpinning countless trace-driven tools.
  10. CACTI: An Enhanced Cache Access and Cycle Time Model
    DOIDOI
    Wilton, Jouppi, 1996, IEEE JSSC. The analytical cache/SRAM access-time/area/energy model embedded in later tools.
  11. Automatically Characterizing Large Scale Program Behavior (SimPoint)
    PDFDOI · PDF
    Sherwood, Perelman, Hamerly, Calder, 2002, ASPLOS-X. Phase analysis making long workloads tractable to simulate.
  12. Simics: A Full System Simulation Platform
    DOIDOI
    Magnusson et al., 2002, IEEE Computer. The landmark commercial full-system functional simulator.
