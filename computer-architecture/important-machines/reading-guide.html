Computer architecture · Important machines & ISAs

Landmark computers and instruction sets, told through their system-description and retrospective papers — the machines that fixed the vocabulary and the ISAs that endured. (Techniques they pioneered are treated in the mechanism subtopics.)

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. Design Objectives for the IBM Stretch Computer
    DOIDOI
    S. W. Dunwell, 1957, Eastern JCC. The IBM 7030 Stretch: pipelining, instruction lookahead, interrupts, the 8-bit byte.
  2. A New Approach to the Functional Design of a Digital Computer
    DOIDOI
    R. S. Barton, 1961, Western JCC. The design manifesto behind the Burroughs B5000 stack architecture.
  3. One-Level Storage System
    DOIDOI
    Kilburn, Edwards, Lanigan, Sumner, 1962, IRE Trans. Electronic Computers. The Manchester Atlas paging scheme — the first practical virtual memory.
  4. Architecture of the IBM System/360
    DOIDOI
    Amdahl, Blaauw, Brooks, 1964, IBM J. R&D. ISA-as-durable-contract: one architecture across a whole model line.
  5. Parallel Operation in the Control Data 6600
    DOIDOI
    J. E. Thornton, 1964, AFIPS FJCC. The first scoreboarded out-of-order supercomputer; an archetypal load/store design.
  6. The IBM System/360 Model 91: Machine Philosophy and Instruction-Handling
    DOIDOI
    Anderson, Sparacio, Tomasulo, 1967, IBM J. R&D. The original description of Tomasulo's algorithm in situ.
  7. VAX-11/780: A Virtual Address Extension to the DEC PDP-11 Family
    DOIDOI
    W. D. Strecker, 1978, AFIPS NCC. The quintessential CISC 32-bit minicomputer (later the RISC-debate foil).
  8. The CRAY-1 Computer System
    DOIDOI
    R. M. Russell, 1978, CACM. The canonical description of the defining vector supercomputer.
  9. The Intel 8086 Microprocessor: A 16-bit Evolution of the 8080
    DOIDOI
    Morse, Pohlman, Ravenel, 1978, IEEE Computer. The origin of the x86 ISA, still the dominant instruction set.
  10. The 801 Minicomputer
    DOIDOI
    G. Radin, 1982, ASPLOS-I. IBM's 801 — the progenitor of RISC and compiler-driven load/store design.
  11. A VLSI RISC (Berkeley RISC-I)
    DOIDOI
    Patterson, Séquin, 1982, IEEE Computer. Reduced instruction set, register windows, single-chip VLSI economics.
  12. MIPS: A Microprocessor Architecture
    DOIDOI
    Hennessy, Jouppi, Przybylski, Rowen, Gross, Baskett, Gill, 1982, MICRO-15. A deeply pipelined RISC pushing hazard handling into the compiler.
  13. A 160-MHz, 32-b, 0.5-W CMOS RISC Microprocessor (StrongARM SA-110)
    DOIDOI
    Montanaro, Witek, Anne, et al., 1996, IEEE JSSC. The implementation that made ARM viable for high-performance, low-power.
  14. Tuning the Pentium Pro Microarchitecture (P6)
    DOIDOI
    David B. Papworth, 1996, IEEE Micro. The x86 landmark: a CISC ISA run as a high-performance OoO core via μop decode.
  15. The Alpha 21264 Microprocessor
    DOIDOI
    R. E. Kessler, 1999, IEEE Micro. An aggressive OoO superscalar RISC; a high-water mark for single-thread performance.
  16. The AMD Opteron Processor for Multiprocessor Servers
    DOIDOI
    Keltcher, McGrath, Ahmed, Conway, 2003, IEEE Micro. AMD64: the 64-bit x86 extension, integrated memory controller, HyperTransport.
