# Computer architecture · Important machines & ISAs

Landmark computers and instruction sets, told through their system-description and
retrospective papers — the machines that fixed the vocabulary and the ISAs that
endured. (Techniques they pioneered are treated in the mechanism subtopics.)

- **Design Objectives for the IBM Stretch Computer** — S. W. Dunwell, 1957, Eastern JCC. The IBM 7030 Stretch: pipelining, instruction lookahead, interrupts, the 8-bit byte. [DOI](https://doi.org/10.1145/1455533.1455540)
- **A New Approach to the Functional Design of a Digital Computer** — R. S. Barton, 1961, Western JCC. The design manifesto behind the Burroughs B5000 stack architecture. [DOI](https://doi.org/10.1145/1460690.1460736)
- **One-Level Storage System** — Kilburn, Edwards, Lanigan, Sumner, 1962, IRE Trans. Electronic Computers. The Manchester Atlas paging scheme — the first practical virtual memory. [DOI](https://doi.org/10.1109/TEC.1962.5219356)
- **Architecture of the IBM System/360** — Amdahl, Blaauw, Brooks, 1964, IBM J. R&D. ISA-as-durable-contract: one architecture across a whole model line. [DOI](https://doi.org/10.1147/rd.82.0087)
- **Parallel Operation in the Control Data 6600** — J. E. Thornton, 1964, AFIPS FJCC. The first scoreboarded out-of-order supercomputer; an archetypal load/store design. [DOI](https://doi.org/10.1145/1464039.1464045)
- **The IBM System/360 Model 91: Machine Philosophy and Instruction-Handling** — Anderson, Sparacio, Tomasulo, 1967, IBM J. R&D. The original description of Tomasulo's algorithm in situ. [DOI](https://doi.org/10.1147/rd.111.0008)
- **VAX-11/780: A Virtual Address Extension to the DEC PDP-11 Family** — W. D. Strecker, 1978, AFIPS NCC. The quintessential CISC 32-bit minicomputer (later the RISC-debate foil). [DOI](https://doi.org/10.1016/B978-0-932376-00-8.50026-8)
- **The CRAY-1 Computer System** — R. M. Russell, 1978, CACM. The canonical description of the defining vector supercomputer. [DOI](https://doi.org/10.1145/359327.359336)
- **The Intel 8086 Microprocessor: A 16-bit Evolution of the 8080** — Morse, Pohlman, Ravenel, 1978, IEEE Computer. The origin of the x86 ISA, still the dominant instruction set. [DOI](https://doi.org/10.1109/C-M.1978.218219)
- **The 801 Minicomputer** — G. Radin, 1982, ASPLOS-I. IBM's 801 — the progenitor of RISC and compiler-driven load/store design. [DOI](https://doi.org/10.1145/960120.801824)
- **A VLSI RISC (Berkeley RISC-I)** — Patterson, Séquin, 1982, IEEE Computer. Reduced instruction set, register windows, single-chip VLSI economics. [DOI](https://doi.org/10.1109/MC.1982.1654133)
- **MIPS: A Microprocessor Architecture** — Hennessy, Jouppi, Przybylski, Rowen, Gross, Baskett, Gill, 1982, MICRO-15. A deeply pipelined RISC pushing hazard handling into the compiler. [DOI](https://doi.org/10.1145/1014194.800930)
- **A 160-MHz, 32-b, 0.5-W CMOS RISC Microprocessor (StrongARM SA-110)** — Montanaro, Witek, Anne, et al., 1996, IEEE JSSC. The implementation that made ARM viable for high-performance, low-power. [DOI](https://doi.org/10.1109/JSSC.1996.542315)
- **Tuning the Pentium Pro Microarchitecture (P6)** — David B. Papworth, 1996, IEEE Micro. The x86 landmark: a CISC ISA run as a high-performance OoO core via μop decode. [DOI](https://doi.org/10.1109/40.491458)
- **The Alpha 21264 Microprocessor** — R. E. Kessler, 1999, IEEE Micro. An aggressive OoO superscalar RISC; a high-water mark for single-thread performance. [DOI](https://doi.org/10.1109/40.755465)
- **The AMD Opteron Processor for Multiprocessor Servers** — Keltcher, McGrath, Ahmed, Conway, 2003, IEEE Micro. AMD64: the 64-bit x86 extension, integrated memory controller, HyperTransport. [DOI](https://doi.org/10.1109/MM.2003.1196116)
