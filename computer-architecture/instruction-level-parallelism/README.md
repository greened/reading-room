# Computer architecture · Instruction-level parallelism

- **An Efficient Algorithm for Exploiting Multiple Arithmetic Units** — Robert M. Tomasulo, 1967, IBM J. R&D. *foundational.* Register renaming + the common data bus — the basis of every modern out-of-order engine. [DOI](https://doi.org/10.1147/rd.111.0025)
- **Two-Level Adaptive Training Branch Prediction** — Tse-Yu Yeh, Yale N. Patt, 1991, MICRO-24. *foundational.* History-register-plus-pattern-table prediction, the template for correlating predictors. [DOI](https://doi.org/10.1145/123465.123475)
- **Combining Branch Predictors** — Scott McFarling, 1993, DEC WRL TN-36. *foundational.* Defines gshare and the tournament/combining predictor (shipped in the Alpha 21264). [PDF](https://www.ece.ucdavis.edu/~akella/270W05/mcfarling93combining.pdf)
