# Computer architecture · Warehouse-scale computing

The datacenter as the unit of computing: cluster architecture, storage, networks,
power, and the systems that schedule it all.

- **The Datacenter as a Computer** — Barroso, Hölzle, 2009, Synthesis Lectures. Framed the datacenter itself as the unit of computing (the WSC abstraction). [DOI](https://doi.org/10.2200/S00193ED1V01Y200905CAC006)
- **Web Search for a Planet: The Google Cluster Architecture** — Barroso, Dean, Hölzle, 2003, IEEE Micro. Reliable planet-scale search on unreliable commodity hardware. [DOI](https://doi.org/10.1109/MM.2003.1196112)
- **The Google File System** — Ghemawat, Gobioff, Leung, 2003, SOSP. A scalable fault-tolerant DFS for commodity clusters. [DOI](https://doi.org/10.1145/945445.945450)
- **MapReduce: Simplified Data Processing on Large Clusters** — Dean, Ghemawat, 2008 (orig. OSDI 2004), CACM. Fault-tolerant large-scale data processing made routine. [DOI](https://doi.org/10.1145/1327452.1327492)
- **Power Provisioning for a Warehouse-sized Computer** — Fan, Weber, Barroso, 2007, ISCA. Measured power revealing headroom for power oversubscription. [DOI](https://doi.org/10.1145/1273440.1250665)
- **A Scalable, Commodity Data Center Network Architecture** — Al-Fares, Loukissas, Vahdat, 2008, SIGCOMM. The fat-tree/Clos design for full-bisection bandwidth on commodity switches. [DOI](https://doi.org/10.1145/1402958.1402967)
- **The Case for RAMCloud** — Ousterhout et al., 2011, CACM. All data in DRAM across a datacenter for low latency. [DOI](https://doi.org/10.1145/1965724.1965751)
- **The Tail at Scale** — Dean, Barroso, 2013, CACM. Named and tamed tail-latency variability in large fan-out services. [DOI](https://doi.org/10.1145/2408776.2408794)
- **Jupiter Rising: A Decade of Clos Topologies and Centralized Control in Google's Datacenter Network** — Singh et al., 2015, SIGCOMM. Five generations of Clos fabrics with SDN control. [DOI](https://doi.org/10.1145/2785956.2787508)
- **Large-scale Cluster Management at Google with Borg** — Verma et al., 2015, EuroSys. The cluster manager that inspired Kubernetes. [DOI](https://doi.org/10.1145/2741948.2741964)
- **Network Requirements for Resource Disaggregation** — Gao et al., 2016, OSDI. The network latency/bandwidth needed to make disaggregation viable. [page](https://www.usenix.org/conference/osdi16/technical-sessions/presentation/gao)
