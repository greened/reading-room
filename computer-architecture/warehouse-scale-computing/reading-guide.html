Computer architecture · Warehouse-scale computing

The datacenter as the unit of computing: cluster architecture, storage, networks, power, and the systems that schedule it all.

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. The Datacenter as a Computer
    DOIDOI
    Barroso, Hölzle, 2009, Synthesis Lectures. Framed the datacenter itself as the unit of computing (the WSC abstraction).
  2. Web Search for a Planet: The Google Cluster Architecture
    DOIDOI
    Barroso, Dean, Hölzle, 2003, IEEE Micro. Reliable planet-scale search on unreliable commodity hardware.
  3. The Google File System
    DOIDOI
    Ghemawat, Gobioff, Leung, 2003, SOSP. A scalable fault-tolerant DFS for commodity clusters.
  4. MapReduce: Simplified Data Processing on Large Clusters
    DOIDOI
    Dean, Ghemawat, 2008 (orig. OSDI 2004), CACM. Fault-tolerant large-scale data processing made routine.
  5. Power Provisioning for a Warehouse-sized Computer
    DOIDOI
    Fan, Weber, Barroso, 2007, ISCA. Measured power revealing headroom for power oversubscription.
  6. A Scalable, Commodity Data Center Network Architecture
    DOIDOI
    Al-Fares, Loukissas, Vahdat, 2008, SIGCOMM. The fat-tree/Clos design for full-bisection bandwidth on commodity switches.
  7. The Case for RAMCloud
    DOIDOI
    Ousterhout et al., 2011, CACM. All data in DRAM across a datacenter for low latency.
  8. The Tail at Scale
    DOIDOI
    Dean, Barroso, 2013, CACM. Named and tamed tail-latency variability in large fan-out services.
  9. Jupiter Rising: A Decade of Clos Topologies and Centralized Control in Google's Datacenter Network
    DOIDOI
    Singh et al., 2015, SIGCOMM. Five generations of Clos fabrics with SDN control.
  10. Large-scale Cluster Management at Google with Borg
    DOIDOI
    Verma et al., 2015, EuroSys. The cluster manager that inspired Kubernetes.
  11. Network Requirements for Resource Disaggregation
