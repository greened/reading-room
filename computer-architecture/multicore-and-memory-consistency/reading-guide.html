Computer architecture · Multicore & memory consistency

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. How to Make a Multiprocessor Computer That Correctly Executes Multiprocess Programs
    DOIDOI
    Leslie Lamport, 1979, IEEE TC. The definition of sequential consistency.
  2. Shared Memory Consistency Models: A Tutorial
    PDFDOI · PDF
    Adve, Gharachorloo, 1996, IEEE Computer. The canonical map of relaxed-consistency models.
  3. Transactional Memory: Architectural Support for Lock-Free Data Structures
    PDFDOI · PDF
    Herlihy, Moss, 1993, ISCA-20. Launched hardware transactional memory (root of Intel TSX).
  4. Simultaneous Multithreading: Maximizing On-Chip Parallelism
    PDFDOI · PDF
    Tullsen, Eggers, Levy, 1995, ISCA-22. The SMT paper that became Hyper-Threading.
  5. The Case for a Single-Chip Multiprocessor
    PDFDOI · PDF
    Olukotun, Nayfeh, Hammond, Wilson, Chang, 1996, ASPLOS-VII. The Hydra argument that many simple cores beat one wide core.
  6. Dark Silicon and the End of Multicore Scaling
    PDFDOI · PDF
    Esmaeilzadeh, Blem, St. Amant, Sankaralingam, Burger, 2011, ISCA-38. Models how the end of Dennard scaling caps usable cores.
