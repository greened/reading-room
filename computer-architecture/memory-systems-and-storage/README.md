# Computer architecture · Memory systems & storage

- **Cache Memories** — Alan Jay Smith, 1982, ACM Computing Surveys. *foundational.* The definitive early survey of the cache design space. [DOI](https://doi.org/10.1145/356887.356892) · [PDF](https://people.engr.tamu.edu/djimenez/taco/utsa-www/cs5513-fall07/reader/smith-cache-memories.pdf)
- **An Adaptive, Non-Uniform Cache Structure for Wire-Delay Dominated On-Chip Caches (NUCA)** — Kim, Burger, Keckler, 2002, ASPLOS-X. *foundational.* Treats a large last-level cache as a distance-varying network. [DOI](https://doi.org/10.1145/605397.605420) · [PDF](https://users.cs.utah.edu/~rajeev/cs7810/papers/kim02.pdf)
- **A Case for Redundant Arrays of Inexpensive Disks (RAID)** — Patterson, Gibson, Katz, 1988, SIGMOD. *foundational.* The RAID-levels taxonomy underpinning modern storage. [DOI](https://doi.org/10.1145/50202.50214)
- **Flipping Bits in Memory Without Accessing Them (RowHammer)** — Kim et al., 2014, ISCA-41. *post-2002.* DRAM density turns activation patterns into reliability/security failures. [DOI](https://doi.org/10.1109/ISCA.2014.6853210)
