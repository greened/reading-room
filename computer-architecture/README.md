# Computer architecture

Reading lists for computer architecture, organized by subtopic. Each subtopic
holds verified, annotated paper references (DOI + open-PDF links where a free copy
exists). **[landmark-papers/](landmark-papers/)** is the cross-cutting survey.

## Subtopics
- **[landmark-papers/](landmark-papers/)** — the area survey (start here; printable PDF)
- **[quantitative-principles/](quantitative-principles/)** — Amdahl, RISC, Dennard, memory wall, roofline, golden age
- **[superscalar-and-out-of-order/](superscalar-and-out-of-order/)** — dynamic scheduling, renaming, precise state, ILP limits
- **[branch-prediction-and-speculation/](branch-prediction-and-speculation/)** — branch predictors and data-value speculation
- **[memory-systems-and-storage/](memory-systems-and-storage/)** — caches, NUCA, DRAM, RAID, flash, persistent memory
- **[multicore-and-memory-consistency/](multicore-and-memory-consistency/)** — consistency, coherence, transactional memory, SMT/CMP
- **[domain-specific-accelerators/](domain-specific-accelerators/)** — systolic arrays, GPUs, FPGAs, DNN accelerators
- **[warehouse-scale-computing/](warehouse-scale-computing/)** — datacenter architecture, storage, networks, cluster management
- **[simulation-and-modeling-tools/](simulation-and-modeling-tools/)** — simulators and power/area/DRAM models
- **[hardware-security/](hardware-security/)** — microarchitectural side channels and transient-execution attacks
- **[weird-architectures/](weird-architectures/)** — dataflow, transport-triggered, VLIW, SIMD, tiled processors
- **[important-machines/](important-machines/)** — landmark machines and ISAs (CDC 6600, System/360, Cray-1, RISC/MIPS, VAX, Alpha, x86)
