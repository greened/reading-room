# Computer architecture · Domain-specific accelerators

The specialization era in silicon: systolic arrays, GPUs, FPGAs, and the DNN
accelerator lineage.

- **Why Systolic Architectures?** — H. T. Kung, 1982, IEEE Computer. The manifesto for systolic arrays, foundational to modern ML accelerators. [DOI](https://doi.org/10.1109/MC.1982.1653825)
- **NVIDIA Tesla: A Unified Graphics and Computing Architecture** — Lindholm, Nickolls, Oberman, Montrym, 2008, IEEE Micro. The unified-shader/CUDA architecture that made GPUs general-purpose compute. [DOI](https://doi.org/10.1109/MM.2008.31)
- **A Reconfigurable Fabric for Accelerating Large-Scale Datacenter Services (Catapult)** — Putnam et al., 2014, ISCA. Datacenter-scale FPGA acceleration. [DOI](https://doi.org/10.1109/ISCA.2014.6853195)
- **DianNao: A Small-Footprint High-Throughput Accelerator for Ubiquitous Machine-Learning** — Chen, Du, Sun, Wang, Wu, Chen, Temam, 2014, ASPLOS. The compact DNN accelerator centered on memory-access energy. [DOI](https://doi.org/10.1145/2541940.2541967)
- **DaDianNao: A Machine-Learning Supercomputer** — Chen, Luo, Liu, Zhang, He, Wang, Li, Chen, Xu, Sun, Temam, 2014, MICRO-47. Multi-chip accelerator with on-chip eDRAM for weights. [DOI](https://doi.org/10.1109/MICRO.2014.58)
- **Eyeriss: A Spatial Architecture for Energy-Efficient Dataflow for CNNs** — Chen, Emer, Sze, 2016, ISCA. Row-stationary dataflow that minimizes data-movement energy. [DOI](https://doi.org/10.1109/ISCA.2016.40)
- **EIE: Efficient Inference Engine on Compressed Deep Neural Network** — Han et al., 2016, ISCA. Inference directly on pruned/compressed sparse networks. [DOI](https://doi.org/10.1109/ISCA.2016.30)
- **In-Datacenter Performance Analysis of a Tensor Processing Unit (TPU)** — Jouppi et al., 2017, ISCA. Google's production systolic matrix unit; the landmark DSA case study. [DOI](https://doi.org/10.1145/3079856.3080246)
- **A Configurable Cloud-Scale DNN Processor for Real-Time AI (Brainwave)** — Fowers et al., 2018, ISCA. A cloud FPGA NPU for real-time, low-batch DNN serving. [DOI](https://doi.org/10.1109/ISCA.2018.00012)
