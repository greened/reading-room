# Programming languages · Semantics & language design

- **The Next 700 Programming Languages** — P. J. Landin, 1966, CACM. Frames the whole family of languages around a small applicative core (ISWIM). [DOI](https://doi.org/10.1145/365230.365257) · [PDF](https://www.cs.cmu.edu/~crary/819-f09/Landin66.pdf)
- **An Axiomatic Basis for Computer Programming** — C. A. R. Hoare, 1969, CACM. Introduces Hoare logic and the pre/postcondition triple. [DOI](https://doi.org/10.1145/363235.363259)
- **A Structural Approach to Operational Semantics** — Gordon D. Plotkin, 1981/2004, JLAP. Founds structural operational semantics (SOS). [DOI](https://doi.org/10.1016/j.jlap.2004.05.001) · [PDF](https://homepages.inf.ed.ac.uk/gdp/publications/sos_jlap.pdf)
- **Abstract Interpretation** — Patrick & Radhia Cousot, 1977, POPL. The lattice/Galois-connection theory underlying sound static analysis. [DOI](https://doi.org/10.1145/512950.512973) · [PDF](https://www.di.ens.fr/~cousot/publications.www/CousotCousot-POPL-77-ACM-p238--252-1977.pdf)
- **Toward a Mathematical Semantics for Computer Languages** — Scott, Strachey, 1971, Oxford PRG-6. The founding statement of denotational semantics. [PDF](https://www.cs.ox.ac.uk/files/3228/PRG06.pdf)
- **Definitional Interpreters for Higher-Order Programming Languages** — John C. Reynolds, 1972, ACM Annual Conf. Defunctionalization; meta-circular vs definitional interpreters. [DOI](https://doi.org/10.1145/800194.805852)
- **A Syntactic Approach to Type Soundness** — Wright, Felleisen, 1994, Information and Computation. The standard progress-and-preservation soundness method. [DOI](https://doi.org/10.1006/inco.1994.1093)
- **The Syntactic Theories of Sequential Control and State** — Felleisen, Hieb, 1992, TCS. Reduction semantics of control and state via evaluation contexts. [DOI](https://doi.org/10.1016/0304-3975(92)90014-7)
- **Recursive Functions of Symbolic Expressions… (LISP), Part I** — John McCarthy, 1960, CACM. Defined LISP; launched functional programming. [DOI](https://doi.org/10.1145/367177.367199)
- **Fundamental Concepts in Programming Languages** — Christopher Strachey, 1967/2000, HOSC. l-values/r-values, parametric vs ad-hoc polymorphism, first-class values. [DOI](https://doi.org/10.1023/A:1010000313106)
