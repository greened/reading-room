Programming Languages — Landmark Papers

A cross-cutting survey of the field's most important papers. Folder: reading-room/programming-languages/ · canonical references live in the sibling subtopic dirs.

Roughly a dozen papers that define programming-language theory and practice, in a sensible reading order (language design and types, then logics, memory models, and modern type systems). Each entry points to the subtopic dir that treats it in depth.   Legend: PDFopen copy available (see fetch.sh) · DOIpublisher link only.

  1. The Next 700 Programming Languages — P. J. Landin
    PDFCACM 1966 · doi:10.1145/365230.365257 · → semantics-and-language-design/
    Frames the whole family of languages around a small applicative core (ISWIM).
  2. An Axiomatic Basis for Computer Programming — C. A. R. Hoare
    DOICACM 1969 · doi:10.1145/363235.363259 · → program-logics-and-verification/
    Introduces Hoare logic and the pre/postcondition triple — the origin of program logics.
  3. Towards a Theory of Type Structure — John C. Reynolds
    PDFProgramming Symposium 1974 · doi:10.1007/3-540-06859-7_148 · → types-and-polymorphism/
    Introduces the polymorphic lambda calculus (System F), the backbone of typed functional languages.
  4. Abstract Interpretation: A Unified Lattice Model for Static Analysis — Patrick & Radhia Cousot
    PDFPOPL 1977 · doi:10.1145/512950.512973 · → semantics-and-language-design/
    The lattice-and-Galois-connection theory underlying essentially all sound static analysis.
  5. A Theory of Type Polymorphism in Programming — Robin Milner
    PDFJCSS 1978 · doi:10.1016/0022-0000(78)90014-4 · → types-and-polymorphism/
    Gives let-polymorphism and Algorithm W, the type-inference core of ML/Haskell.
  6. Comprehending Monads — Philip Wadler
    PDFLFP 1990 · doi:10.1145/91556.91592 · → monads-and-effects/
    Brings Moggi's monads into practical programming — effectful pure functional code made tractable.
  7. Separation Logic: A Logic for Shared Mutable Data Structures — John C. Reynolds
    DOILICS 2002 · doi:10.1109/LICS.2002.1029817 · → program-logics-and-verification/
    The frame rule and local reasoning about heap-manipulating programs.
  8. The Java Memory Model — Manson, Pugh, Adve
    PDFPOPL 2005 · doi:10.1145/1040305.1040336 · → concurrency-and-memory-models/
    The first rigorous language-level memory model (data-race-freedom, happens-before).
  9. Gradual Typing for Functional Languages — Siek, Taha
    PDFScheme Workshop 2006 · scheme2006 · → practical-type-systems/
    Coins gradual typing and the consistency relation for mixing static and dynamic checking.
  10. seL4: Formal Verification of an OS Kernel — Klein et al.
    PDFSOSP 2009 · doi:10.1145/1629575.1629596 · → program-logics-and-verification/
    First machine-checked functional-correctness proof of a general-purpose OS kernel.
  11. Mathematizing C++ Concurrency — Batty, Owens, Sarkar, Sewell, Weber
    PDFPOPL 2011 · doi:10.1145/1926385.1926394 · → concurrency-and-memory-models/
    Formalizes the C11/C++11 relaxed-atomics model, the template for modern concurrency standards.
  12. RustBelt: Securing the Foundations of the Rust Programming Language — Jung, Jourdan, Krebbers, Dreyer
    PDFPOPL 2018 · doi:10.1145/3158154 · → program-logics-and-verification/
    First formal safety proof for a realistic Rust subset, reconciling unsafe libraries with a safe type system.

Reference shelf — books

The standard texts for the area; free copies linked where a legal one exists.

  • BUYTypes and Programming Languages (TAPL) — Benjamin C. Pierce (2002) · the standard graduate introduction to type systems. page
  • BUYAdvanced Topics in Types and Programming Languages — Pierce (ed.) (2005) · deeper chapters: dependent types, effects, modules. page
  • FREEPractical Foundations for Programming Languages — Robert Harper (2nd ed., 2016) · reconstructs language features from type-structure first principles (free abridged PDF). PDF
  • BUYThe Formal Semantics of Programming Languages — Glynn Winskel (1993) · accessible first course in operational/denotational/axiomatic semantics. page
  • FREESoftware Foundations — Pierce et al. · machine-checked (Coq/Rocq) course in logic, PL semantics, verification (free HTML). page
  • FREEConcrete Semantics with Isabelle/HOL — Nipkow, Klein (2014) · operational semantics + verification, fully mechanized (free PDF). PDF
  • FREECertified Programming with Dependent Types — Adam Chlipala (2013) · building certified programs and proofs in Coq (free PDF). PDF
