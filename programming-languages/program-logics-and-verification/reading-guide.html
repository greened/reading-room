Programming languages · Program logics & verified systems

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. A Behavioral Notion of Subtyping
    DOIDOI
    Liskov, Wing, 1994, ACM TOPLAS. Makes the substitution principle precise.
  2. Separation Logic: A Logic for Shared Mutable Data Structures
    DOIDOI
    John C. Reynolds, 2002, LICS. The frame rule and local reasoning about the heap.
  3. Resources, Concurrency, and Local Reasoning
    DOIDOI
    Peter W. O'Hearn, 2007, TCS. Concurrent separation logic.
  4. seL4: Formal Verification of an OS Kernel
    PDFDOI · PDF
    Klein et al., 2009, SOSP. First machine-checked functional-correctness proof of a general-purpose kernel.
  5. Formal Verification of a Realistic Compiler (CompCert)
    PDFDOI · PDF
    Xavier Leroy, 2009, CACM. End-to-end machine-checked semantic preservation.
  6. RustBelt: Securing the Foundations of the Rust Programming Language
    PDFDOI · PDF
    Jung, Jourdan, Krebbers, Dreyer, 2018, POPL. First formal safety proof for a realistic Rust subset.
  7. Guarded Commands, Nondeterminacy and Formal Derivation of Programs
    DOIDOI
    Dijkstra, 1975, CACM. Weakest-precondition predicate transformers + guarded commands.
  8. An Axiomatic Proof Technique for Parallel Programs I
    DOIDOI
    Owicki, Gries, 1976, Acta Informatica. Hoare logic for shared-variable concurrency (interference freedom).
  9. Local Reasoning about Programs that Alter Data Structures
    DOIDOI
    O'Hearn, Reynolds, Yang, 2001, CSL. Separation logic framed around local reasoning + the frame rule.
  10. Proof-Carrying Code
    DOIDOI
    George C. Necula, 1997, POPL. Untrusted code ships a machine-checkable safety proof.
  11. Iris: Monoids and Invariants as an Orthogonal Basis for Concurrent Reasoning
    PDFDOI · PDF
    Jung et al., 2015, POPL. The foundational modern concurrent separation-logic framework.
  12. Dafny: An Automatic Program Verifier for Functional Correctness
    DOIDOI
    K. Rustan M. Leino, 2010, LPAR-16. The Dafny language + SMT-backed verifier.
