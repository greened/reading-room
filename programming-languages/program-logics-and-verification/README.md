# Programming languages · Program logics & verified systems

- **A Behavioral Notion of Subtyping** — Liskov, Wing, 1994, ACM TOPLAS. Makes the substitution principle precise. [DOI](https://doi.org/10.1145/197320.197383)
- **Separation Logic: A Logic for Shared Mutable Data Structures** — John C. Reynolds, 2002, LICS. The frame rule and local reasoning about the heap. [DOI](https://doi.org/10.1109/LICS.2002.1029817)
- **Resources, Concurrency, and Local Reasoning** — Peter W. O'Hearn, 2007, TCS. Concurrent separation logic. [DOI](https://doi.org/10.1016/j.tcs.2006.12.035)
- **seL4: Formal Verification of an OS Kernel** — Klein et al., 2009, SOSP. First machine-checked functional-correctness proof of a general-purpose kernel. [DOI](https://doi.org/10.1145/1629575.1629596) · [PDF](https://plsyssec.github.io/cse227-spring25/papers/sel4.pdf)
- **Formal Verification of a Realistic Compiler (CompCert)** — Xavier Leroy, 2009, CACM. End-to-end machine-checked semantic preservation. [DOI](https://doi.org/10.1145/1538788.1538814) · [PDF](https://xavierleroy.org/publi/compcert-CACM.pdf)
- **RustBelt: Securing the Foundations of the Rust Programming Language** — Jung, Jourdan, Krebbers, Dreyer, 2018, POPL. First formal safety proof for a realistic Rust subset. [DOI](https://doi.org/10.1145/3158154) · [PDF](https://plv.mpi-sws.org/rustbelt/popl18/paper.pdf)
- **Guarded Commands, Nondeterminacy and Formal Derivation of Programs** — Dijkstra, 1975, CACM. Weakest-precondition predicate transformers + guarded commands. [DOI](https://doi.org/10.1145/360933.360975)
- **An Axiomatic Proof Technique for Parallel Programs I** — Owicki, Gries, 1976, Acta Informatica. Hoare logic for shared-variable concurrency (interference freedom). [DOI](https://doi.org/10.1007/BF00268134)
- **Local Reasoning about Programs that Alter Data Structures** — O'Hearn, Reynolds, Yang, 2001, CSL. Separation logic framed around local reasoning + the frame rule. [DOI](https://doi.org/10.1007/3-540-44802-0_1)
- **Proof-Carrying Code** — George C. Necula, 1997, POPL. Untrusted code ships a machine-checkable safety proof. [DOI](https://doi.org/10.1145/263699.263712)
- **Iris: Monoids and Invariants as an Orthogonal Basis for Concurrent Reasoning** — Jung et al., 2015, POPL. The foundational modern concurrent separation-logic framework. [DOI](https://doi.org/10.1145/2676726.2676980) · [PDF](https://iris-project.org/pdfs/2015-popl-iris1-final.pdf)
- **Dafny: An Automatic Program Verifier for Functional Correctness** — K. Rustan M. Leino, 2010, LPAR-16. The Dafny language + SMT-backed verifier. [DOI](https://doi.org/10.1007/978-3-642-17511-4_20)
