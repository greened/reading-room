# Programming languages · Concurrency & memory models

- **A Calculus of Mobile Processes, I** — Milner, Parrow, Walker, 1992, Information and Computation. The pi-calculus. [DOI](https://doi.org/10.1016/0890-5401(92)90008-4) · [PDF](https://www.cis.upenn.edu/~stevez/cis670/pdfs/pi-calculus.pdf)
- **The Java Memory Model** — Manson, Pugh, Adve, 2005, POPL. The first rigorous language-level memory model (data-race-freedom, happens-before). [DOI](https://doi.org/10.1145/1040305.1040336) · [PDF](http://rsim.cs.uiuc.edu/Pubs/popl05.pdf)
- **Mathematizing C++ Concurrency** — Batty, Owens, Sarkar, Sewell, Weber, 2011, POPL. Formalizes the C11/C++11 relaxed-atomics model. [DOI](https://doi.org/10.1145/1926385.1926394) · [PDF](https://www.cl.cam.ac.uk/~pes20/cpp/popl085ap-sewell.pdf)
- **Communicating Sequential Processes (CSP)** — C. A. R. Hoare, 1978, CACM. Foundational message-passing concurrency. [DOI](https://doi.org/10.1145/359576.359585)
- **A Calculus of Communicating Systems (CCS)** — Robin Milner, 1980, LNCS 92. Algebraic, compositional theory of concurrent processes. [DOI](https://doi.org/10.1007/3-540-10235-3)
- **Time, Clocks, and the Ordering of Events in a Distributed System** — Leslie Lamport, 1978, CACM. Happens-before and logical clocks. [DOI](https://doi.org/10.1145/359545.359563) · [PDF](https://lamport.azurewebsites.net/pubs/time-clocks.pdf)
- **Threads Cannot Be Implemented as a Library** — Hans-J. Boehm, 2005, PLDI. Why threading needs first-class language/memory-model support. [DOI](https://doi.org/10.1145/1065010.1065042)
- **x86-TSO: A Rigorous and Usable Programmer's Model for x86 Multiprocessors** — Sewell, Sarkar, Owens, Zappa Nardelli, Myreen, 2010, CACM. A precise total-store-order model for real x86. [DOI](https://doi.org/10.1145/1785414.1785443) · [PDF](https://www.cl.cam.ac.uk/~pes20/weakmemory/cacm.pdf)
- **A Promising Semantics for Relaxed-Memory Concurrency** — Kang, Hur, Lahav, Vafeiadis, Dreyer, 2017, POPL. Resolves out-of-thin-air for relaxed atomics. [DOI](https://doi.org/10.1145/3009837.3009850) · [PDF](https://people.mpi-sws.org/~dreyer/papers/promising/paper.pdf)
