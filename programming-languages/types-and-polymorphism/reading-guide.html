Programming languages · Types, polymorphism & abstraction

In-depth landmark list for this subtopic. PDFopen copy available · DOIpublisher link only.

  1. Towards a Theory of Type Structure
    PDFDOI · PDF
    John C. Reynolds, 1974, Programming Symposium (LNCS 19). Introduces the polymorphic lambda calculus (System F).
  2. A Theory of Type Polymorphism in Programming
    PDFDOI · PDF
    Robin Milner, 1978, JCSS. Let-polymorphism and Algorithm W. 90014-4)
  3. Principal Type-Schemes for Functional Programs
    PDFDOI · PDF
    Damas, Milner, 1982, POPL. The formal foundation of Hindley-Milner inference.
  4. On Understanding Types, Data Abstraction, and Polymorphism
    PDFDOI · PDF
    Cardelli, Wegner, 1985, ACM Computing Surveys. The definitive synthesis of polymorphism, subtyping, and abstraction.
  5. Theorems for Free!
    DOIDOI
    Philip Wadler, 1989, FPCA. Turns parametricity into free theorems.
  6. Interprétation fonctionnelle… (System F)
    DOI
    Jean-Yves Girard, 1972, Thèse d'État, Paris VII. Introduced System F (second-order lambda calculus) and reducibility.
  7. Abstract Types Have Existential Type
    DOIDOI
    Mitchell, Plotkin, 1988, ACM TOPLAS. ADTs are precisely existential types; the basis of data abstraction/modules.
  8. How to Make ad-hoc Polymorphism Less ad hoc (type classes)
    DOIDOI
    Wadler, Blott, 1989, POPL. Introduced type classes.
  9. Local Type Inference
    DOIDOI
    Pierce, Turner, 2000, ACM TOPLAS. Practical inference for subtyping + explicit polymorphism.
  10. Complete and Easy Bidirectional Typechecking for Higher-Rank Polymorphism
    PDFDOI · PDF
    Dunfield, Krishnaswami, 2013, ICFP. The standard bidirectional algorithm blueprint.
  11. OutsideIn(X): Modular Type Inference with Local Assumptions
    PDFDOI · PDF
    Vytiniotis, Peyton Jones, Schrijvers, Sulzmann, 2011, JFP. GHC's inference for GADTs/type families.
