# Programming languages · Types, polymorphism & abstraction

- **Towards a Theory of Type Structure** — John C. Reynolds, 1974, Programming Symposium (LNCS 19). Introduces the polymorphic lambda calculus (System F). [DOI](https://doi.org/10.1007/3-540-06859-7_148) · [PDF](https://www.cis.upenn.edu/~stevez/cis670/pdfs/Reynolds74.pdf)
- **A Theory of Type Polymorphism in Programming** — Robin Milner, 1978, JCSS. Let-polymorphism and Algorithm W. [DOI](https://doi.org/10.1016/0022-0000(78)90014-4) · [PDF](https://research.cs.queensu.ca/home/cordy/cisc860/Biblio/hurd/misc/milner78.pdf)
- **Principal Type-Schemes for Functional Programs** — Damas, Milner, 1982, POPL. The formal foundation of Hindley-Milner inference. [DOI](https://doi.org/10.1145/582153.582176) · [PDF](https://courses.cs.washington.edu/courses/cse503/10wi/readings/p207-damas.pdf)
- **On Understanding Types, Data Abstraction, and Polymorphism** — Cardelli, Wegner, 1985, ACM Computing Surveys. The definitive synthesis of polymorphism, subtyping, and abstraction. [DOI](https://doi.org/10.1145/6041.6042) · [PDF](https://lucacardelli.name/papers/onunderstanding.a4.pdf)
- **Theorems for Free!** — Philip Wadler, 1989, FPCA. Turns parametricity into free theorems. [DOI](https://doi.org/10.1145/99370.99404)
- **Interprétation fonctionnelle… (System F)** — Jean-Yves Girard, 1972, Thèse d'État, Paris VII. Introduced System F (second-order lambda calculus) and reducibility.
- **Abstract Types Have Existential Type** — Mitchell, Plotkin, 1988, ACM TOPLAS. ADTs are precisely existential types; the basis of data abstraction/modules. [DOI](https://doi.org/10.1145/44501.45065)
- **How to Make ad-hoc Polymorphism Less ad hoc (type classes)** — Wadler, Blott, 1989, POPL. Introduced type classes. [DOI](https://doi.org/10.1145/75277.75283)
- **Local Type Inference** — Pierce, Turner, 2000, ACM TOPLAS. Practical inference for subtyping + explicit polymorphism. [DOI](https://doi.org/10.1145/345099.345100)
- **Complete and Easy Bidirectional Typechecking for Higher-Rank Polymorphism** — Dunfield, Krishnaswami, 2013, ICFP. The standard bidirectional algorithm blueprint. [DOI](https://doi.org/10.1145/2500365.2500582) · [PDF](https://arxiv.org/pdf/1306.6032)
- **OutsideIn(X): Modular Type Inference with Local Assumptions** — Vytiniotis, Peyton Jones, Schrijvers, Sulzmann, 2011, JFP. GHC's inference for GADTs/type families. [DOI](https://doi.org/10.1017/S0956796811000098) · [PDF](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/jfp-outsidein.pdf)
