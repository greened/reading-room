# Machine learning · Sequence models

- **Long Short-Term Memory** — Hochreiter, Schmidhuber, 1997, Neural Computation. The gated recurrent cell that dominated sequence modeling for two decades. [DOI](https://doi.org/10.1162/neco.1997.9.8.1735)
- **Efficient Estimation of Word Representations in Vector Space (word2vec)** — Mikolov, Chen, Corrado, Dean, 2013, ICLR Workshop. Cheap, semantically meaningful word embeddings. [arXiv](https://arxiv.org/abs/1301.3781) · [PDF](https://arxiv.org/pdf/1301.3781)

- **Generating Sequences With Recurrent Neural Networks** — Graves, 2013, arXiv. LSTMs generate long-range coherent text and handwriting. [arXiv](https://arxiv.org/abs/1308.0850) · [PDF](https://arxiv.org/pdf/1308.0850)
- **Deep Contextualized Word Representations (ELMo)** — Peters et al., 2018, NAACL. Deep contextual embeddings; the move to pretrained contextual reps. [arXiv](https://arxiv.org/abs/1802.05365) · [PDF](https://arxiv.org/pdf/1802.05365)
- **GloVe: Global Vectors for Word Representation** — Pennington, Socher, Manning, 2014, EMNLP. Global log-bilinear word vectors, a standard embedding baseline. [page](https://aclanthology.org/D14-1162/) · [PDF](https://aclanthology.org/D14-1162.pdf)
- **Pointer Networks** — Vinyals, Fortunato, Jaitly, 2015, NeurIPS. Attention that points at input positions; precursor to copy/attention. [arXiv](https://arxiv.org/abs/1506.03134) · [PDF](https://arxiv.org/pdf/1506.03134)
