# Machine learning · Computer vision (CNNs & detection)

- **ImageNet Classification with Deep Convolutional Neural Networks (AlexNet)** — Krizhevsky, Sutskever, Hinton, 2012, NeurIPS. The ImageNet win that started the modern deep-learning boom. [page](https://papers.nips.cc/paper/4824-imagenet-classification-with-deep-convolutional-neural-networks) · [PDF](https://www.image-net.org/static_files/files/supervision.pdf)
- **Very Deep Convolutional Networks for Large-Scale Image Recognition (VGG)** — Simonyan, Zisserman, 2015, ICLR. Depth with small 3x3 filters; a durable transfer-learning backbone. [arXiv](https://arxiv.org/abs/1409.1556) · [PDF](https://arxiv.org/pdf/1409.1556)
- **Faster R-CNN: Towards Real-Time Object Detection with Region Proposal Networks** — Ren, He, Girshick, Sun, 2015, NeurIPS. The reference two-stage detector. [arXiv](https://arxiv.org/abs/1506.01497) · [PDF](https://arxiv.org/pdf/1506.01497)
- **You Only Look Once (YOLO)** — Redmon, Divvala, Girshick, Farhadi, 2016, CVPR. Detection as single-shot regression — the real-time paradigm. [arXiv](https://arxiv.org/abs/1506.02640) · [PDF](https://arxiv.org/pdf/1506.02640)
- **Going Deeper with Convolutions (GoogLeNet/Inception)** — Szegedy et al., 2015, CVPR. The multi-branch Inception module; depth with controlled compute. [arXiv](https://arxiv.org/abs/1409.4842) · [PDF](https://arxiv.org/pdf/1409.4842)
- **Fully Convolutional Networks for Semantic Segmentation** — Long, Shelhamer, Darrell, 2015, CVPR. Made per-pixel dense prediction end-to-end trainable. [arXiv](https://arxiv.org/abs/1411.4038) · [PDF](https://arxiv.org/pdf/1411.4038)
- **U-Net: Convolutional Networks for Biomedical Image Segmentation** — Ronneberger, Fischer, Brox, 2015, MICCAI. Encoder-decoder with skip connections; the default segmentation (and diffusion) backbone. [arXiv](https://arxiv.org/abs/1505.04597) · [PDF](https://arxiv.org/pdf/1505.04597)
- **Mask R-CNN** — He, Gkioxari, Dollár, Girshick, 2017, ICCV. Faster R-CNN + a mask branch; the instance-segmentation standard. [arXiv](https://arxiv.org/abs/1703.06870) · [PDF](https://arxiv.org/pdf/1703.06870)
- **EfficientNet: Rethinking Model Scaling** — Tan, Le, 2019, ICML. Compound scaling of depth/width/resolution for accuracy at far lower FLOPs. [arXiv](https://arxiv.org/abs/1905.11946) · [PDF](https://arxiv.org/pdf/1905.11946)
