Files are numbered 01–13 by topic, but the order below is pedagogical: build intuition first, read the core architecture, fill in the details it only references, then the refinements, then the three model families. Companion explainers (video / web / PDF) are slotted in where they help most.

Why is it called a “Transformer”? Honestly, none of the papers spell this out — “Attention Is All You Need” just names the model in its abstract. The name comes from sequence transduction: the model transforms an input sequence into an output sequence, and, layer by layer, transforms every token’s representation by mixing in context from the others (via attention) — rather than recurring over the sequence (RNNs) or convolving a local window (CNNs). So the reading list doesn’t define the name, but paper 01 (§3, the encoder/decoder stacks) and the 3Blue1Brown video show exactly the “transform the representation” picture the name refers to.

Key equations, in plain English

The handful of equations at the heart of paper 01 (§3.2–§3.5) — each with what it means and what it does. This is the notation the rest of the guide keeps pointing at.

The forward pass, end to end. text → tokenize (BPE / WordPiece / SentencePiece — papers 11–13) → token ids → embed (E × √dmodel — paper 10) → + positional encoding → N × blocks [ multi-head self-attention → add&norm → FFN → add&norm ] (paper 01 §3) → de-embed (ET — paper 10) → softmax → next-token probabilities.
Encoder-only (BERT): those blocks with attention unmasked. Decoder-only (GPT): attention masked so each token sees only earlier ones. Original (paper 01): both — the decoder block adds a second, cross-attention sub-layer that reads the encoder’s output.
Notation key.   x — a token’s vector (its current representation), width dmodel.   Q, K, V — Queries, Keys, Values: three learned linear views of the tokens (Q = “what I’m looking for,” K = “what I offer,” V = “what I’d hand over”).   dk — width of each key/query, per head.   h — number of heads.   W∗ — learned weight matrices.   softmax — turns a row of scores into positive weights that sum to 1.
  1. Attention(Q, K, V) = softmax( Q KT / √dk ) V
    Math: dot each query with every key → a grid of scores; scale by √dk; softmax each row into weights; take the weighted sum of the value vectors.
    Effect: every token pulls in a blend of the other tokens’ values, weighted by relevance — “reading from” the sequence by content. Dividing by √dk just keeps the scores from growing large and flattening softmax’s gradients as dk grows.
  2. MultiHead(…) = Concat(head1,…,headh) WO,   headi = Attention(Q WiQ, K WiK, V WiV)
    Math: run h attentions in parallel on different learned projections of Q/K/V; concatenate the results; project back with WO.
    Effect: each head can specialize (one tracks syntax, another long-range coreference, another position), so the model attends to several kinds of relationship at once.
  3. PE(pos, 2i) = sin( pos / 100002i/dmodel ),   PE(pos, 2i+1) = cos( pos / 100002i/dmodel )
    Math: add a fixed vector of sinusoids at geometrically-spaced frequencies to each token embedding, keyed to the token’s position.
    Effect: attention alone is order-blind (it treats the input as a set); this injects “where in the sequence” so word order carries meaning.
  4. y = LayerNorm( x + Sublayer(x) );   FFN(x) = max(0, x W1 + b1) W2 + b2
    Math: every sub-layer (attention or FFN) adds its output back onto its input (a residual) then normalizes; the FFN is a small per-token 2-layer MLP with a ReLU in the middle.
    Effect: residuals let gradients flow through a very deep stack; LayerNorm keeps activations well-scaled; the FFN gives each token independent “compute” between the attention mixes. (Paper 09 is precisely about where to place that LayerNorm.)
  5. in:  et = √dmodel · E[tokent] + PE(t)   ——   out:  logits = h ET → softmax
    Math: the input embedding picks row tokent from a learned matrix E (scaled by √dmodel) and adds the positional vector. At the output, the final hidden state h is multiplied by ET to score every vocabulary entry, and softmax turns those scores into next-token probabilities.
    Effect: tokens become vectors on the way in and vectors become vocabulary scores on the way out — and the same matrix E does both (weight tying, paper 10), so “embedding” and “de-embedding” are one learned object.

Key terms

The vocabulary these papers assume.

token — the atomic unit of input (a subword piece), mapped to an integer id.   embedding — the learned vector a token id maps to.   positional encoding — a per-position vector added to embeddings so order matters.   attention — a weighted read where each token pulls in others' information by relevance.   Q / K / V — query, key, value: three learned projections used to compute attention.   head — one independent attention computation; multi-head runs several in parallel.   softmax — turns scores into positive weights that sum to 1.   logits — the pre-softmax output scores (here, one per vocabulary entry).   residual connection — adding a sub-layer's input to its output so gradients flow.   layer normalization — rescaling activations to keep them well-behaved.   FFN — the per-token feed-forward (2-layer MLP) sub-layer.   causal / masked attention — attention restricted so a token sees only earlier tokens (decoder-only / generation).   encoder / decoder — the two block stacks; encoders see the whole input, decoders generate left-to-right.   pretraining / fine-tuning — train once on a broad objective, then adapt to a task.   context length — how many tokens the model can attend over at once.   parameter — a learned weight; model size is counted in these.
