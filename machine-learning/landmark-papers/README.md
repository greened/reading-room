# Machine learning · landmark papers (survey)

A cross-cutting survey — the most important machine-learning papers across the
area's subtopics, in a sensible reading order. Canonical, in-depth references live
in the sibling subtopic directories (and the transformer papers live in
`../transformers/`). Run `./fetch.sh` to download the openly-available PDFs.

1. **Rumelhart, Hinton & Williams, Learning representations by back-propagating errors** (1986) — backprop. → *deep-learning-foundations*
2. **Hochreiter & Schmidhuber, Long Short-Term Memory** (1997) — the gated recurrent cell. → *sequence-models*
3. **Krizhevsky, Sutskever & Hinton, AlexNet** (2012) — the ImageNet breakthrough. → *computer-vision*
4. **Mikolov et al., word2vec** (2013) — learned word embeddings. → *sequence-models*
5. **Kingma & Welling, Auto-Encoding Variational Bayes (VAE)** (2013) — deep latent-variable generation. → *generative-models*
6. **Goodfellow et al., Generative Adversarial Nets** (2014) — adversarial generation. → *generative-models*
7. **Sutskever, Vinyals & Le, Sequence to Sequence Learning** (2014) — the encoder-decoder framework. → *sequence-models*
8. **Mnih et al., Human-level control through deep RL (DQN)** (2015) — deep reinforcement learning. → *reinforcement-learning*
9. **He et al., Deep Residual Learning (ResNet)** (2016) — residual connections. → *deep-learning-foundations*
10. **Silver et al., Mastering the game of Go (AlphaGo)** (2016) — learned search. → *reinforcement-learning*
11. **Ho, Jain & Abbeel, Denoising Diffusion Probabilistic Models** (2020) — diffusion generation. → *generative-models*
12. **Kaplan et al., Scaling Laws for Neural Language Models** (2020) — the empirical basis for scale-up. → *training-and-scaling*

The transformer architecture and its model families (Attention Is All You Need,
BERT, GPT, ViT) have their own in-depth list in **`../transformers/`**.
