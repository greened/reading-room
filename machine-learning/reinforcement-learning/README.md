# Machine learning · Reinforcement learning

- **Human-level control through deep reinforcement learning (DQN)** — Mnih et al., 2015, Nature. Learned Atari from pixels; founded deep RL. [DOI](https://doi.org/10.1038/nature14236) · [PDF](https://web.stanford.edu/class/psych209/Readings/MnihEtAlHassibis15NatureControlDeepRL.pdf)
- **Mastering the game of Go with deep neural networks and tree search (AlphaGo)** — Silver et al., 2016, Nature. Deep policy/value nets + MCTS beat top humans at Go. [DOI](https://doi.org/10.1038/nature16961)
- **Proximal Policy Optimization Algorithms (PPO)** — Schulman, Wolski, Dhariwal, Radford, Klimov, 2017, arXiv. The robust policy-gradient method that became the RL/RLHF default. [arXiv](https://arxiv.org/abs/1707.06347) · [PDF](https://arxiv.org/pdf/1707.06347)
- **Learning to Predict by the Methods of Temporal Differences** — Sutton, 1988, Machine Learning. Introduced TD learning, RL's foundational bootstrapping method. [DOI](https://doi.org/10.1007/BF00115009)
- **Q-learning** — Watkins, Dayan, 1992, Machine Learning. The canonical model-free off-policy control algorithm, with convergence proof. [DOI](https://doi.org/10.1007/BF00992698)
- **Simple Statistical Gradient-Following Algorithms (REINFORCE)** — Williams, 1992, Machine Learning. The REINFORCE policy-gradient family. [DOI](https://doi.org/10.1007/BF00992696)
- **Asynchronous Methods for Deep RL (A3C)** — Mnih et al., 2016, ICML. Lightweight asynchronous actor-critic beating prior deep-RL SOTA. [arXiv](https://arxiv.org/abs/1602.01783) · [PDF](https://arxiv.org/pdf/1602.01783)
- **Continuous Control with Deep RL (DDPG)** — Lillicrap et al., 2016, ICLR. Deep Q-learning extended to continuous action spaces. [arXiv](https://arxiv.org/abs/1509.02971) · [PDF](https://arxiv.org/pdf/1509.02971)
- **Trust Region Policy Optimization (TRPO)** — Schulman et al., 2015, ICML. Monotonic-improvement guarantees for stable policy optimization. [arXiv](https://arxiv.org/abs/1502.05477) · [PDF](https://arxiv.org/pdf/1502.05477)
- **AlphaZero: Mastering Chess and Shogi by Self-Play** — Silver et al., 2017, arXiv. Superhuman chess/shogi/Go from self-play with one general algorithm. [arXiv](https://arxiv.org/abs/1712.01815) · [PDF](https://arxiv.org/pdf/1712.01815)
- **MuZero: Mastering Atari, Go, Chess and Shogi by Planning with a Learned Model** — Schrittwieser et al., 2020, Nature. Matched AlphaZero without being given the rules. [arXiv](https://arxiv.org/abs/1911.08265) · [PDF](https://arxiv.org/pdf/1911.08265)
